# 02 — Proposed README §9 policy rows (staging)

Status: **proposed, non-normative staging.** The accepted scoped policy baseline puts the inventory in README §9, "not in a new service or competing policy register" (`README.md:440`; [accepted scoped policy baseline](../../README.md#accepted-scoped-policy-baseline)). Master edits are outside this package's authorization, so the rows are staged here until the master's owner moves them into §9 ([X-001](consistency/master-contradictions.md#x-001)). Until then:

- **README §9 and the decision IDs are the authority.** These rows only show where each approval was found, its scope and how far it is verified.
- **How other documents cite a policy.** Specs and the traceability matrix cite a policy by its decision ID, with a POL ID as a pointer only.
- **No new approvals.** Nothing here approves, changes or chooses a policy. Where the record and the code disagree, the row says **conflict** and links an owner question; the target does not pick a side.
- **Legacy defaults are not policy.** A legacy default or docstring becomes a policy row only when an owner decision covers it (`README.md:442`).

## How to read a row

| Column | Meaning |
|---|---|
| Decision | Owner decision ID and date in the AT register `docs/OWNER-DECISIONS.md` at `445eb116` (cited `OD:<line>`), a historical record |
| Scope | Strategy, family, account, environment or host the approval applies to |
| Code | What the AT code or shipped defaults at `445eb116` actually do (cited `path:line`). "record only" means the behaviour was not re-verified in code in this session |
| Target owner | The module (README §6; index in [05-module-index.md](05-module-index.md)) that must carry the policy |
| Status | **A** applicable approval (preserve) · **H** historical or host-specific setting (not a target-wide default) · **S** superseded (do not implement) · **C** conflict (owner question) · **O** open owner decision (do not choose) · **L** legacy-architecture choice already replaced by an accepted target decision |
| Oracle | The independent expected outcome a target test must assert, derived from the decision text and not from code |

Every row with status A is carried as a requirement key in [traceability.md](traceability.md). C and O rows link to [decisions/owner-questions.md](decisions/owner-questions.md).
